---
title: Jalapeno Crema Salsa
author: Ian Sherman
description: Based off salsas in PV
ingredients:
  - { qty: "8", item: "Whole jalapeños" }
  - { qty: "1/2 cup", item: "Water" }
  - { qty: "1/2 cup", item: "Oil (olive or canola)" }
  - { qty: "1", item: "Egg yolk" }
  - { qty: "1 small bunch”, item: "Cilantro (Optional)" }
equipment:
  - { type: "", item: "Blender" }
ingredientsYouHave:
  - 1 tsp Salt
  - Pepper to taste
  - Oil
---
- Halve and seed the jalapeños. 
- Place jalapeños, water, egg yolk, cilantro, salt, and pepper in the blender. 
  - Blend until completely pureed. Note: it should not be too hot, so don’t do soup mode. 
  - While bending at medium speed, drizzle in the oil VERY slowly--a drop at a time or a very thin stream. 
- Taste for seasoning, seal, and refrigerate.
	- Once cold, shake to remix.
	- NOTE: It’s been hard to keep this salsa from breaking. This should work, but it’s still a work in progress.
