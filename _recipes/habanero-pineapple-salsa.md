---
title: Habanero Pineapple Salsa
author: Ian Sherman
description: Based loosely on the salsa we had at Macareno (I think)
ingredients:
  - { qty: "1 20 oz can", item: "Crushed pineapple in juice" }
  - { qty: "1/4", item: "Red onion" }
  - { qty: "1/2", item: "Habanero" }
  - { qty: "1", item: "Garlic clove" }
  - { qty: "3 Tbsp", item: "Lime juice" }
  - { qty: "1 tsp", item: "Fresh oregano, minced" }
  - { qty: "1.5 tsp", item: "Salt" }
  - { qty: "1.5 tsp", item: "Sugar" }
equipment:
  - { type: "1-quart", item: "jar" }
  - [ type: "1", item: "molcajete" }
ingredientsYouHave:
  - Salt
  - Sugar
  - Fresh Oregano
---
- Grind the habaneros, garlic, salt, sugar and oregano in the molcajete. - Add the lime juice and grind until well macerated.
- Add 1/3 of the crushed pineapple to the molcajete and grind until mixed. 
- Add the mix from the molcajete to a jar together with the remaining pineapple. Season and adjust taste. 
- Mix, shake, and refrigerate overnight. 
- Notes on this recipe: grinding in a molcajete enhances all the flavor. Garlic is stronger, habanero is spicier.
