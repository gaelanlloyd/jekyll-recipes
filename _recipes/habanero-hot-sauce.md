---
title: Habanero Hot Sauce
author: Ian Sherman
description: A VERY hot sauce with a carrot base
ingredients:
  - { qty: "3-4", item: "Carrots" }
  - { qty: "15-20", item: "Habaneros" }
  - { qty: "2", item: "Garlic cloves" }
  - { qty: "1/4 Cup", item: "Lime juice" }
  - { qty: "2 tsp", item: "Salt" }
equipment:
  - { type: "", item: "Vitamix blender" }
ingredientsYouHave:
  - Salt
---
- Chop carrots into large chunks and add to blender.
- Remove stems from habaneros and add to blender.
- Add all remaining ingredients to blender. 
- Set blender on "soup" mode and run program. Hot sauce should be hot and steaming. Bottle and let sit overnight in refrigerator.
